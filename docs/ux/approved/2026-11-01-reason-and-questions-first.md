# Approved: visible reason, and questions first

- **Approved by:** Sebas (PO), 2026-11-01, after trying the prototype.
- **Source:** `docs/ux/proposals/2026-11-01-gymstudio-prototype.md`, evidence in `docs/ux/proposals/2026-11-01-fitbod-review.md`.
- **Prototype:** https://claude.ai/artifact/XZeKFk4YzJGt5PKz4Xv5bh (private; the PO can share it).

## What was approved

### 1. The reason for the weight is visible

The sentence that explains today's weight appears above the Done button while logging, without opening the cue sheet. It uses the engine's existing reason. Tips and other first-week help are not part of this approval.

### 2. Questions first, workout today

A new user answers a few short questions before creating an account, creates the account, and sees today's workout the same day instead of waiting for next Monday.

**Still to be decided by the PT before this is built:** the questions, which plan day comes first on each weekday, the first partial week, first-session weights, and the wording of the medical notice.

## What was not approved

Short on time, machine taken, plate calculator, removing the Google button, the achievement card, hiding "+x kg/week", a delete-account path different from #384, and any preview without an account. These stay in the proposal.
