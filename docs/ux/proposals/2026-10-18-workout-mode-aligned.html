Aligned Workout mode (UXer, 2026-10-18)
Prototype only, not built. Blends the current #304/#308 Workout mode (chips, all sets visible, Last time column, rest bar) with the 10-07 super-simple feel (one big logger, auto rest, clear Next).

Try it
  • Start workout, press Log set on each set. Rest starts on its own.
  • On an exercise's last set, an insight card shows for 3 s, then folds into the Done list. Tap the card to keep it open.
  • 3+4 and 5+6 are supersets (one round = both exercises). 2 is a reverse pyramid. 7 is a drop set.
  • After the last set: Completed.
