## Question 1 - "I have no workouts with 4 reps. Is that OK?"

**Short answer: yes, it is expected and fine for a muscle goal, and a small dose of heavy work is still worth adding.**

- The lowest reps anywhere in blocks 1-9 are **6** (blocks 3 and 7, strength blocks). Hypertrophy
  blocks never go below 8. That is by design.
- Muscle growth is similar across a wide load range (about 30-85% of 1RM, roughly 5-30 reps)
  **as long as sets end close to failure** (Schoenfeld 2017/2021). So 4-rep sets are not needed to grow.
- Why a little heavy work still helps an intermediate lifter:
  1. Strength built at 3-6 reps lets you use heavier loads in later 8-12-rep blocks (more tension per rep).
  2. Heavy sets give the most "growth stimulus per set" for very little fatigue (few reps).
  3. It keeps the strength skill on the main lifts, which slowly fades if you never go heavy.
- Why not a lot of it: at 3-5 reps you need more sets to match growth from moderate loads (Schoenfeld
  2014: 7x3 matched 3x10 for growth but took far longer and beat up the joints more). Heavy sets also
  carry more joint and technique risk.

**Recommendation:** add **one heavy top set of 4-5 reps** on the main compound lift of each **A day**
in block 7 (strength block) and block 9 (reverse-pyramid block), followed by lighter back-off sets.
Keep B days and block 8 at 6+ reps. That is ~3 heavy sets per week, about 5-8% of weekly volume.

**Safety rules for heavy sets**
- Only on stable or well-practised lifts (Smith bench, seated or Smith press, squat with safety pins, rows).
- Stop 1-2 reps before failure (RIR 1-2); never grind or fail a heavy barbell set.
- Warm up in 3-4 ramp sets (e.g. 50% x 8, 70% x 4, 85% x 2) before the top set.
- Use safety pins or a spotter; skip the top set on days when sleep or joints are bad.
- Any joint pain during heavy sets: drop back to 6-8 reps and see a qualified professional.
- No heavy top sets in week 1 (learning loads) or week 6 (deload).

## Techniques: what they are, evidence, app support today

| Technique | What it is | Evidence / best use | App support today |
|---|---|---|---|
| Straight sets | Same load and reps every set | Default; easiest to progress | Yes (`straight`) |
| Superset | Two exercises back to back, then rest | Antagonist or non-competing pairs save time, same growth | Yes (`superset`, codes B1/B2) |
| Drop set | Set to near failure, cut load ~20-30%, continue | Same growth as straight sets in less time (Coleman 2022); isolation/machine, last set, 1-2 per session | Yes (`drop-set`, reps "12+12") |
| Pyramid (ascending) | Load up, reps down each set | No special effect; early sets act as warm-up | Yes (`pyramid`) |
| Reverse pyramid / top set + back-off | Heaviest set first, then ~10% lighter for more reps | Keeps every set close to failure; good vehicle for a heavy top set | Yes (`reverse-pyramid`) |
| Double angle | Same movement at two bench angles, e.g. 30° then 0° | Trains two regions of the chest; doing the harder angle first then the easier one lets you keep going (a "mechanical drop set") | **Partly.** Two consecutive rows with different `angle_degrees` work today (as `straight` sets, or as `superset` codes C1/C2 with 10 s rest). There is no `double-angle` label, so the app would call it a "superset". |
| Rest-pause | Set near failure, rest 15-20 s, 2 mini-sets more | Similar growth to straight sets, time-efficient; machines/isolation only | **No** - needs new technique value or notes |
| Myo-reps | Activation set (12-20 reps) then 3-5 mini-sets of 3-5 reps with ~5 breaths rest | Variant of rest-pause; good for laterals, calves, arms | **No** |
| Lengthened partials | After full reps reach failure, add 4-6 half reps in the stretched position | Stretch-biased training matches or beats full ROM (Wolf 2023; Pedrosa 2022; Kassiano 2023) | **No** (can only go in `notes`) |
| Tempo / slow eccentric | e.g. 3 s lowering, 1 s pause in the stretch | Not better for growth by itself, but good for learning and controlling stretch; avoid very slow (>8 s) reps | **No** (notes only) |

## Proposed revision for blocks 7-9

General rules for all three blocks:
- **Per session:** max 1 heavy top set (A days only), max 2 intensity techniques (drop set, rest-pause, myo-reps, partials), always on the **last set** of a **machine, cable or isolation** exercise. Never on squats, deadlifts, RDLs or barbell presses.
- Exercises and set counts stay as approved unless listed below, so weekly volume stays inside 10-20 sets per muscle.

## Safety notes
- Intensity techniques add fatigue; if performance drops two sessions in a row, remove them for a week.
- Rest-pause, myo-reps and partials only on machines, cables and isolation lifts.
- Heavy sets: warm-up ramp, safety pins/spotter, RIR 1-2, no failure.
- Not medical advice. Any pain during training: stop the exercise and see a qualified professional.
